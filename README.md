## 🐍 The pitch

My first Python practice file — a little bit of everything I was learning: asking the user for input, converting types, playing with strings, and building a product-price calculator with tax.

<a id="run"></a>
## ▶️ Run it

```bash
python first-python-practice.py
```

The script asks you for a superhero name, an age, and product details, then prints the results and their data types.

<a id="quiz"></a>
<details>
<summary>🎯 Can you predict the output? — click to reveal</summary>

**Question:** if you type `shahida` into the string section, what does `my_name[1]` print?

**Answer:** `h` — indexing starts at 0, so index 1 is the second character.

**Bonus:** `my_name.find("ram")` returns `-1` because that text isn't in the string.

</details>

<a id="concepts"></a>
<details>
<summary>📌 Concepts covered — click to expand</summary>

- Reading input and converting it with `int()`, `float()` and `str()`
- Calculating subtotal, tax amount and final total from a tax percentage
- Checking a variable's type with `type()`
- Strings are immutable — `.upper()` returns a new string, it doesn't change the original
- Indexing, `.find()` and `.replace()` on strings
